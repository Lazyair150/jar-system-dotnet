## 3. 硬约束（不许改变的东西）

1. **规则语义**：形状转换三级规则、禁令边界（不影响满罐转移）、一罐一操作、满罐需求限制（设计定案不放宽）、选择性转移、容量溢出/回滚溢出**直接丢弃不回收**。
2. **对外 JSON 契约**：`GetState()` 的全部字段名/层级，以及路径步骤的 14 个字段（`step/requirement/operation/type/jarIndex/jarId/jarShape/jarLiquid/targetShape/targetLiquid/costLiquid/reshapeMode/consumed/jarsAfter`）。现在由 `Services/StateDtos.cs` 与 `Orders/SolverStepDto.cs` 的 `[JsonPropertyName]` **钉死**；前端 `wwwroot/js/app.js` 依赖这些键。
2b. ⚠️ **`autoCheckResults` 消息的契约面**（2026-08 新发现，此前未记录）：`OrderService.CheckAllFeasibility` 用匿名对象**直接内嵌 `FeasibilityResultData` 本体**（未经 DTO 投影），因此该类**属性名本身就是契约**：`feasible/blockage/reason/timestamp/directCount/operationCount/solverPath/masterPath/path/directSatisfactions/operationsNeeded/stats/checkMethod/transferJarIds/transferLiquids`。⇒ `FeasibilityResultData.Path`、`.Stats` 虽然恒为 null、且不在 `GetState()` 的 DTO 里，**也不能删除**（会改变该消息的键集合）。
3. **WebSocket 命令/消息契约**：18 个命令名（`CommandDispatcher.HandleCoreAsync` 的 `case` 数；前端 `app.js` 实际发送其中 15 个）、**10 种消息名**（`init`/`state`/`orderExecuted`/`workshopSwitched`/`feasibilityResult`/`allFeasibilityResults`/`autoCheckResults`/`autoCheckChanged`/`error` + **`world`**）与 payload 键集合。
   > `world`（S4）是**连接时一次性**下发的世界元数据（形状/液体词表）：刻意**不进 `state`** —— 否则每条 state（每 2 秒）都要背一份数组，契约快照也会跟着变长。
   > 计数更正：早期报告写的"19 个命令"是**数错了**，实读为 18（见 §9 勘误）。
4. **测试基线**：`0 bugs / 2000 + 0 bugs / 3000 + 20 deterministic` 必须保持（双向一致性 + 罐子守恒 + 液体非负 + 容量压力）。

## 6. 已知坑与约定（避免重复踩）

- **验证只能由用户执行**；`.bat` 必须纯 ASCII、无 `if (...)` / `for ... do (...)` 括号块、不切 `chcp`（本机实测：LF 换行 + 中文路径会让脚本静默失败）。
- **`问题/` 目录不能移动**：`test/StrategyExperiment/Program.cs` 输出路径写死为相对路径 `问题/问题十测试记录-重跑.txt`。

- **日志编码（易误判为故障）**：`_build_output.txt`（纯 `dotnet` 输出）与 `_contract\state_keys.txt` 是 **UTF-8**；`_verify_output.txt` 是**混合编码**（`.bat` 自己的 `echo` 走 cmd 的 GBK + `dotnet` 输出走 UTF-8）故工具常报"invalid UTF-8"。**控制台里看到的乱码只是 GBK 控制台回显 UTF-8 字节**，与程序正确性无关（见 §10 ③），不要在运行时加 `chcp`/改 `Console.OutputEncoding`。
- **不要用 `taskkill /f /im dotnet.exe`**（会杀掉所有 .NET 进程）；`run.bat` 里有这行，属潜在误伤。
- **待用户手动做的文件操作**（自动化工具有写权限、无删除/改权限）：
  1. 重命名 `src/JarSystem.Core/Executor/IndependentExecutor.cs` → `OrderExecutor.cs`（类名早已是 `OrderExecutor`）；
  2. 删除 `src/JarSystem.Core/Executor/SolverPathAdapter.cs`（阶段 3-D 后已废弃，文件内只剩下说明注释）。
