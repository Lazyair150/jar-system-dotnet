# 陶罐对战 · 规则草案 v0.2

> 取代 v0.1。机制来源：`D:\codex\jar-system-dotnet` 陶罐系统。
> 铁律：机制内核不变，只改承载形态；因果链不能断。

---

## 0. 一句话

你是匠人。你的**工作台**是你在战场上的代理人。**罐子**与**液体**是你的弹药，**攻击卡**是订单——订单要什么，你就得凑什么。

**属性由弹药的成本决定：想打某种属性，你得先有一条能造出它的产线。**

## 1. 核心循环

```
公用仓库 ──(产线/补充卡取货)──> 工作台罐位/液池
                                    │
                              改形 · 装液 · 转移
                                    │
                              凑出攻击卡需求
                                    │
                                  攻击 ──> 对方工作台
                                    │
                      对方回合里动你的罐子 ←── 转移暴露意图
```

## 2. 组件

### 2.1 牌库（每人 50 张，构筑）

| 卡类 | 张数 |
|---|---|
| 工作台卡 | **5** |
| 罐子产线卡 | **10** |
| 液体产线卡 | **6** |
| 补充资源卡（罐子/液体） | **8** |
| A 类攻击卡 | **10** |
| B 类攻击卡 | **6** |
| 变化卡 | **5** |
| **合计** | **50** |

- 起手 **10** 张；每回合开始抽 **4** 张；手牌上限 **10**。

### 2.2 罐子卡（**系统公用堆**，不属任何玩家构筑）

- **8 种形状 × 6 张 = 48 张**，单面
- 卡面只印形状，**中央留白放棋子**
- 产出：公用堆 → 工作台罐位
- 消耗 / 摧毁 / 改形换下：**回公用堆**
- **某形状抽空时**：取一张任意多余的罐子卡**翻到背面**，临时当作该形状使用；离开工作台时翻回正面并归位

### 2.3 棋子（**系统公用堆**，不属任何玩家构筑）

| 棋子 | 液体 |
|---|---|
| 黑棋 | 酒 |
| 白棋 | 蜜 |

- 各 **20 枚**起步（围棋棋子足够；缺失时用象棋红/黑替代）
- **棋子是状态标记，不是筹码**：烧掉的棋子**回公共棋堆**——液体是流转品，产线会继续产
- 液体恰好两种，是原系统宪法（`Config/Vocabulary.cs:8-10`）

### 2.4 其它

血量标记（0–20，每方 2 组） / step 标记（0–4） / 弃置堆（只放玩家牌，不放罐子卡）

### 2.5 三层供给结构

| 层 | 组件 | 归属 | 特性 |
|---|---|---|---|
| **L1 公用仓库** | 棋子堆（黑/白）+ 罐子卡堆（8 形状） | **系统**，不占构筑 | 「这个世界里有这些资源」 |
| **L2 产线** | 资源生产卡 | 玩家构筑 | **慢速、持续、可预期**地取货 |
| **L3 补充** | 补充资源卡（罐子/液体两子类） | 玩家构筑 | **快速、一次性、需暗牌决策**地取货 |

**L1 是货架，L2 与 L3 是两种取货手段。玩家不把"资源本身"放进牌库，牌库里只有"取货权"。**

## 4. 五类卡

### 4.1 工作台卡

**字段**：名称 / **BaseMarks** / **AdditionalMarks** / **Ban** / 血量 **20** / **液池格**

- **BaseMarks** 决定：① 能改形成什么 ② **相克属性**
- **AdditionalMarks** 只决定：能改形成什么。**不参与相克**，也**不能装液体**
- **Ban = 没有该颜色的液池格**
- **液池格按颜色印刷**（黑格 = 酒，白格 = 蜜）；被禁的液体**没有对应格子**
- 血量统一 **20**；"血量作为卡面形状属性"留待以后

**模板**

| 工作台 | BaseMarks | AdditionalMarks | Ban | 液池 |
|---|---|---|---|---|
| 玄武台 | 圆罐、方罐 | 三角罐 | 酒 | 4 白格 |
| 朱雀台 | 高罐 | 长罐 | 酒 | 4 白格 |

### 4.2 资源生产卡

- 字段：产出类型（罐子 / 液体）/ 形状（产罐子时）/ 液体种类（产液体时）/ **速率（分数）**
- **只能放进产线区**
- **产出的罐子直接进主台**
- 速率是分数（如 `0.2/tick`）；**回合结束结算 10 tick**，余数跨回合累计
- 一条产线只产**一种**形状或一种液体

### 4.3 补充资源卡（两个子类）

| 子类 | 效果 |
|---|---|
| **补充罐子卡** | 从公用堆取 N 张指定形状的罐子卡 → 放到指定工作台 |
| **补充液体卡** | 从公共棋堆取 N 枚指定颜色棋子 → 放到指定工作台的液池 |

- **留在手牌为暗牌**，玩家自己决定何时给出、给主台还是从台
- 打出 **0 步**
- **不能突破 Ban**：工作台上没有该颜色的液池格，液体无处安放

### 4.4 攻击卡

- 字段：**需求**（罐子列表）/ 基础伤害 / 效果文字 / **卡类 A 或 B**
- **打出不耗 step**
- 打出时，需求中的罐子**连同其上棋子一并消耗**（回公用堆 / 回棋堆）

| | **A 类** | **B 类** |
|---|---|---|
| 在哪打 | **主台** | **从台** |
| 需求范围 | **只能主台独自满足** | **可主从联合**（跨台需转移） |
| 节奏 | 即时 | 两段式（主台预处理 → 转移 → 从台交付） |
| 强度 | 基准 | **必须整体强于 A 类**，否则是废牌 |

### 4.5 变化卡

- 字段：**step 成本**（卡面印刷，基础档 1）/ 效果
- **不耗资源**
- 可入侵对手 / 对己方产生额外效果

## 5. 回合流程

```
【回合开始】
  1. 从牌库抽 4 张（牌库空 ⇒ 判负）
  2. step 重置为 4

【行动阶段】可任意顺序，累计消耗 step
  · 放置工作台卡                     0 步
  · 放置资源生产卡                   0 步
  · 打出攻击卡（消耗资源）             0 步
  · 打出补充资源卡                   0 步
  · 打出变化卡                       按卡面
  · 罐子操作（入罐/出罐/改形）          每次 1 步
  · 转移（批量、单向）                1 步
  · 换台                             1 步

【回合结束】
  1. 各产线区结算 10 tick 产出
  2. 手牌弃至 10 张
  3. 罐子卡全部重置为竖直
  4. 交接
```

## 6. 资源与操作

### 6.1 罐子

- 每台罐位上限 **6**；超出**直接丢弃**，不回收
- **一罐一操作**：同一回合内，每张罐子卡最多被**操作**一次（转移不算操作）

### 6.2 液体

- 每台液池上限 **4~6 格**，**按该台可存液体着色**
- 液体有两个位置：**液池**（游离）/ **罐子卡上**（装入）
- 一个罐子最多装 **1 枚**棋子

### 6.3 操作表（各 1 步，操作后**横置**）

| 操作 | 条件 | 效果 |
|---|---|---|
| **入罐** | 空罐 + 形状属该台 **BaseMarks** + 液体不被 Ban（该台有该颜色液池格）+ 液池≥1 | 液池 −1 → 罐子卡 +1 |
| **出罐** | 罐子卡上有棋子 + 该台能存储该液体 | 罐子卡 −1 → 液池 +1 |
| **改形（空罐）** | 空罐 + 液池有该台可用的成本液体 | 液池 −1（**消耗**）；形状改变 |
| **改形（满罐）** | 罐子卡上有棋子 | 移除该棋子（**消耗**）；形状改变 |

> **注意**：**入罐只允许 BaseMarks**（`规则.txt:11-13`）。附加标记（三角罐、长罐）**永远不能装液体**，只能服务空罐需求。

### 6.4 横置（Tap）

| 动作 | 性质 | 是否横置 |
|---|---|---|
| 产线产出罐子 | 进货 | **否** |
| 补充卡补入罐子 | 进货 | **否** |
| 主→从 / 从→主 转移 | 搬运 | **否** |
| 入罐 / 出罐 / 改形 | **加工** | **是** |

> **横置只标记「加工」，不标记「物流」。**
>
> ⇒ **改形**产出的是**横置**罐子 ⇒ 只能当**交付罐**（存在即完成）。
> ⇒ **产线**产出的是**竖直**罐子 ⇒ 才能当**工具罐**（还要动手加工）。
> 这条把 `规则.txt:47-50`「改形只能服务空罐需求」落成了物理规则。

- 已在横置状态的罐子**本回合不能再被操作**（但仍可被转移）
- 回合结束时全部重置

> **横置状态跨台保持**——一个罐子转移到另一台后，原来横置的仍然横置，原来竖直的仍然竖直。转移不改变、也不清除它的操作状态。

### 6.5 转移（批量、单向）

> **一次转移动作** = 选定**一个方向**（主→从 **或** 从→主，二选一）
> + **任意数量**的罐子卡（连同其上棋子）
> + 消耗 **1 step**
> + 受目标台罐位上限约束
> + **不改变横置状态**

**为什么必须批量而非每罐 1 步**：按罐计费时，B 类攻击卡的真实成本是「预处理 2~3 步 + 转移 3 罐 = 3 步」，一回合 4 步根本不够 ⇒ B 类会成为「理论上存在、实战中不存在」的卡。批量后 B 类成本 = 预处理 2 步 + 转移 1 步 = 3 步。

### 6.6 改形规则

- **基础标记** → 其它基础标记 + 全部附加标记
- **附加标记** → 只有基础标记（**死胡同**）
- **不在任何标记中** → 全部基础标记

### 6.7 卡死的罐子

**装酒罐**转移到**禁酒台**是允许的（满罐转移不受禁令影响，`规则.txt:19-23`）；但在该台**出罐不允许**（没有黑格）。
⇒ 产生「卡死的罐子」：只能通过 **满罐改形（烧掉酒）/ 转移走 / 被消耗** 三种方式解脱。

## 7. 伤害结算

### 7.1 属性判定（可从需求直接推出，无需记忆）

对需求中每种形状计算**加权和**：

| 罐子状态 | 权重 |
|---|---|
| 空罐 | **1** |
| 装液罐 | **2** |

- **属性 = 加权和最大的形状**
- **平局 = 取需求列表里先出现的**

**例**：`1 空方罐 + 1 装酒圆罐` → 方 1 : 圆 2 ⇒ **圆罐属性**

> 权重就是造价：装液罐 = 罐 1 + 液 1 = 2 个资源单元。

### 7.2 相克乘算

- 攻击卡属性 vs 目标工作台的 **BaseMarks**（不含 AdditionalMarks）
- **克制 ×3/2**，**抵抗 ×2/3**
- **同向只算一次**（多个克制不叠加、多个抵抗不叠加）
- ⇒ 伤害恒在 **[2/3, 3/2]** 倍，最大 2.25 倍差
- **向下取整，最低 1**

### 7.3 目标

**攻击者自行选择打主台还是从台。**

### 7.4 B 类攻击卡的正确流程

1. **主台预处理**：操作（横置）罐子，产出**交付罐**
2. **批量转移（1 步）**：搬走两类罐子
   - **交付罐**——已横置。**交付不是操作**，所以横置不影响它被交付
   - **从台工具罐**——必须是主台**未操作过**的（未横置），转移后仍可在从台操作
3. **从台继续**：只操作**未横置**的工具罐
4. **从台交付**：结算伤害

> **B 类可行的真实原因是「分工」而非「转移清空状态」**：横置状态跨台保持，所以搬到从台的罐子若已在主台被操作过，就再也动不了了。B 类必须精心安排哪些罐子在哪一侧被操作。

## 8. 死亡、替补与胜负

- 工作台血量 ≤ 0 ⇒ **该台连同台上所有罐子卡与液池棋子回公用堆/棋堆**
- **从台死**：位置空着，允许
- **主台死**：
  - 本回合结束前，可主动用手牌工作台卡补入主位
  - 否则回合结束时**从台强制替补为主台**（带剩余血量）
- **场上无任何工作台** ⇒ 进入对方回合，该回合结束仍未补台 ⇒ **判负**

**胜负**：
1. 对方场上无工作台且其回合结束未补台 ⇒ **胜**
2. 对方牌库抽空 ⇒ **胜**
3. 无"玩家血量"——血量挂在工作台上

## 9. 换台流程

想把手牌的工作台卡放到某个位置时：

| 位置状态 | 处理 |
|---|---|
| **空** | 直接放入 |
| **有台，桌上无资源**（无罐子、液池空） | **直接换**，旧台进弃置堆 |
| **有台且台上有资源** | 进入**换台流程** |

**换台流程**（消耗 **1 step**，内部操作不额外耗步）：

- **Ban 相同** ⇒ *Case 1*：把游离液体尽量灌进旧台的 BaseMarks 空罐（新台接收"已装满的罐子"作为额外液体容量）
- **Ban 不同** ⇒ *Case 2*：旧台**临时获得新台 BaseMarks 作为附加标记**，把旧台罐子改形成新台形状；游离液体不强行清空
- 之后按禁令/容量**转移**，未用的资源**回流**；回流溢出直接丢弃
- **主台不能设为从台**

## 10. 首轮与特殊时钟

- **首轮**：双方的第一回合都**不能对对手使用卡牌**（只能建设）
- **产线结算**：**回合结束**结算 10 tick；**本回合放下的产线本回合结束就结算**（资源在下一回合可用）
- **宽限回合**（场上无工作台时）：可放工作台卡、可放产线卡、可用变化卡；**不能操作资源**
- **无打断**：回合独占，对手不能在你的回合出牌；但**转移是公开信息**
- **失败即代价**：已花掉的成本不退（已改形的形状、已消耗的液体、已倒入的液体都留在场上）

## 11. 八属性克制环（提案）

**环序**：圆 → 方 → 三角 → 高 → 长 → 扁 → 鼓 → 尖 →（回圆）
**每个属性克：其后第 1 位、第 3 位**

| 属性 | 克制 | 被克 |
|---|---|---|
| **圆罐** | 方罐、高罐 | 尖罐、扁罐 |
| **方罐** | 三角罐、长罐 | 圆罐、鼓罐 |
| **三角罐** | 高罐、扁罐 | 方罐、尖罐 |
| **高罐** | 长罐、鼓罐 | 圆罐、三角罐 |
| **长罐** | 扁罐、尖罐 | 方罐、高罐 |
| **扁罐** | 鼓罐、圆罐 | 三角罐、长罐 |
| **鼓罐** | 尖罐、方罐 | 高罐、扁罐 |
| **尖罐** | 圆罐、三角罐 | 长罐、鼓罐 |

- 每属性**克 2、被克 2**，完全对称
- **语义可换**：形状的"性格"（方罐多攻击、圆罐多防御、三角罐多机制、长罐多回复）只是**风味文字**，不进数值
- **玄武（圆+方）vs 朱雀（高）**：互相 ×3/2 ⇒ 互相打得都更重
