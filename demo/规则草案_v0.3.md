> 承接 v0.2。本版只做两件事：**把每类卡印成什么样子定下来**，**给出第一副能直接上手打的预组**。

## 0. 相对 v0.2 的修订（共 5 条，后 2 条要你裁决）

| # | 修订 | 理由 |
|---|---|---|
| R1 | §6.4 横置表补入「产线产出 / 补充卡补入 / 转移 = **不横置**」，并写明**横置只标记加工、不标记物流** | 已按你的裁决落盘 |

## 1. 卡面模板

### 1.1 工作台卡

```
┌────────────────────────────────────┐
│  玄武台                       ♥ 20 │
│ ────────────────────────────────── │
│  罐位  □ □ □ □ □ □                 │
│                                    │
│  液池  ● ● ● ●        ●=蜜  ○=酒  │
│        （黑格=酒，白格=蜜）          │
│ ────────────────────────────────── │
│  变形  圆罐 · 方罐  →  三角罐       │
│  属性  圆罐 · 方罐                  │
│ ────────────────────────────────── │
│  禁制  酒   （本台无酒格）           │
└────────────────────────────────────┘
```

**印法要点**
- 液池格**必须印颜色**。Ban 就是「没有那种颜色的格子」，玩家看卡面就知道能装什么，不用查表。
- **属性只列 BaseMarks**；AdditionalMarks 写在「变形」行，不进属性。
- 血量、禁制、属性三者不互相推导，各自印清楚。

### 1.2 罐子卡（公用堆，双面不同）

```
  正面                          背面
┌──────────────┐          ┌──────────────┐
│              │          │              │
│     圆 罐     │          │   陶  ·  罐   │
│              │          │              │
│    ┌──────┐  │          │              │
│    │ 棋位  │  │          │              │
│    └──────┘  │          │              │
└──────────────┘          └──────────────┘
```

- **棋位**就是装液体处。放一枚棋子 = 装了那种液体。
- **背面是通用面**：公用堆某形状抽空时，翻背面顶替（`规则.txt` 无此条，这是 v0.2 §2.2 新增的应急规则）。
- 罐子卡**不属于任何玩家**，消耗后回公用堆。

│ ──────────────────────────────── │

## 2. 八属性的效果倾向（纯风味，不进数值）

用户给定：**方罐=攻击性 / 圆罐=防御性 / 三角罐=机制性 / 长罐=回复**。
我补剩下四个（可随时改，不影响数值）：

| 属性 | 效果倾向 | 补的理由 |
|---|---|---|
| 圆罐 | 防御 · 减伤 · 护台 | 用户定 |
| 方罐 | 攻击 · 直伤 | 用户定 |
| 三角罐 | 机制 · 触发 · 条件 | 用户定 |
| 长罐 | 回复 · 续命 | 用户定 |
| **高罐** | 穿透 · 无视格挡 | 长颈，够得着后面 |
| **扁罐** | 扩散 · 群伤 / 波及产线 | 口宽，泼得开 |
| **鼓罐** | 蓄力 · 暴击（延迟大伤） | 腹大，装得住 |
| **尖罐** | 精准 · 直取单点 | 口细，只戳一个点 |

**注意**：以上**只是写效果文字时的参考口径**，与相克环、伤害数值**完全解耦**（你 Q27 的裁决）。相克只看 BaseMarks 的环位，不看语义。

### 2.1 效果文字只能动三种东西

在「暂不考虑血量与液池」的前提下，攻击卡的效果文字**只有三种可用的成本货币**：

| 货币 | 具体操作 | 例子 |
|---|---|---|
| **伤害数值** | 加减伤害 | 「伤害 +2」 |
| **step（行动经济）** | 增加/夺取对方的行动数 | 「对方下回合 −1 step」 |
| **状态（操作权）** | 横置 / 扶正 / 打碎 / 指定 / 转移 | 「对方 1 张罐子横置」 |

**被排除在外的一类**：**减伤、回复、护台** —— 这三个**必须挂在血量上**。你说暂不考虑血量，所以每个形状给两条：

- **主效果**：只动上面三种货币，**现在就能实现**
- **备选效果**：等血量定案后启用（现在只定方向，不定数值）

### 2.2 八形状的效果文字口径

| 属性 | 倾向 | **主效果（不动血量，现在可用）** | 备选（等血量定案） |
|---|---|---|---|
| **圆罐** | 防御 | **固守**：打出后，对方下回合每打出 1 张攻击卡须额外支付 **1 step** | 本回合受到的伤害 −2 |
| **方罐** | 攻击 | **连击**：若你本回合已打出过攻击卡，此卡**伤害 +2** | 第二次攻击伤害翻倍 |
| **三角罐** | 机制 | **连锁**：若你本回合进行过转移，抽 **1 张牌** | 触发时回复 2 点 |
| **长罐** | 回复 | **续力**：打出后，你本回合 **+1 step** | 回复己方主台 3 点 |
| **高罐** | 穿透 | **越位**：此卡需求**可主从联合满足**（即使它是 A 类） | 无视目标台的属性抵抗 |
| **扁罐** | 扩散 | **波及**：若你打的是主台，对方**从台随机 1 张罐子卡横置** | 从台一并受一半伤害 |
| **鼓罐** | 蓄力 | **蓄势**：此卡不立即结算，改为在**你的下个回合开始**时结算，且 **+3 伤害** | 结算时无视护台 |
| **尖罐** | 精准 | **定点**：此卡伤害**固定，不受克制与抵抗影响** | 无视一切减伤 |

**三条必须同时遵守的硬约束**：

1. **效果必须与属性自洽**。属性是从需求反推的（§7.1 加权），所以效果要顺着那个属性写，不能写反。
2. **预组里的三角罐、长罐是 AdditionalMarks —— 不能装液体**（§6.3）。所以这两个形状的卡**只能依赖空罐**，效果文字**不能要求"装液状态"**。随机池里它们可能成为 BaseMarks，那时才能解锁装液版本。
3. **「越位」不能写成「可在任一台打出」**。那样会模糊 A 类 / B 类的区别（Q38 定的是 A 类只能主台、B 类只能从台）。改成「需求可主从联合满足」后，**位置限制不变、只是需求来源变宽**——高罐的身份是"够得着"，不是"无处不在"。（本版据此改了 §2.2 的这一行与 §3.5 的 A6 / A7。）

### 2.3 设计一张攻击卡的四步

```
① 选形状        → 决定属性（相克关系锁定）
② 定需求        → 决定成本；同时用 §7.1 加权复算，确认属性就是①选的
③ 查 §2.2       → 取该属性的效果口径
④ 定基础伤害    → 参考 §4 的节奏算例（单台 20 血 ÷ 3 回合 ≈ 6~7 伤/回合）
```

> 第 ② 步是最容易出错的地方：**先想好属性，再凑需求，让加权结果正好落在那个属性上。** 反着来（先写需求再看属性）会得到一堆属性错位的卡。

### 2.4 三个走通全流程的样例

| | 例 1 · 圆罐 | 例 2 · 方罐 | 例 3 · 三角罐 |
|---|---|---|---|
| ① 形状 | 圆罐 | 方罐 | 三角罐 |
| ② 需求 | 2 空圆罐 | 2 空方罐 | 1 空三角罐 + 1 空圆罐 |
| ② 复算 | 圆 1+1 = **2** ⇒ 圆 ✅ | 方 1+1 = **2** ⇒ 方 ✅ | 三角 1 : 圆 1 ⇒ 平局取先 ⇒ **三角** ✅ |
| ③ 口径 | 防御 → **固守** | 攻击 → **连击** | 机制 → **连锁** |
| 效果文字 | 对方下回合每张攻击卡 **+1 step** | 若本回合已出攻击卡，**伤害 +2** | 若本回合转移过，**抽 1 张牌** |
| ④ 伤害 | 3 | 3 | 3 |

**另一个由此得出的规矩**：**卡名必须由「属性 + 效果」反推，不能先起名**。

例 3 若沿用预组里的旧名「三角破甲」，但效果是「抽牌」，名与效就对不上了——它该叫「三角连引」之类。§3.5 / §3.6 的 16 张攻击卡名，填效果时**允许一并改名**。

## 3. 第一副预组（镜像，双方完全相同，50 张）

> 镜像预组的目的是**先验证引擎能不能转**，不是验证构筑平衡。双方拿一样的牌，谁赢谁输只取决于操作。

### 3.1 工作台卡 · 5 张

| 卡 | 张数 | BaseMarks（属性） | AdditionalMarks（仅变形） | Ban | 液池 |
|---|---|---|---|---|---|
| 玄武台 | **3** | 圆罐、方罐 | 三角罐 | 酒 | **5 白格** |
| 朱雀台 | **2** | 高罐 | 长罐 | 酒 | 4 白格 |

> 液池格数按 §6.1 定案：**双 base 台 5 格、单 base 台 4 格**。

**为什么 3:2**：玄武能自产圆/方/三角三种形状，双 base 让它在改形上更自由；朱雀只有单一 base 高罐，结构更专精但也更脆。

### 3.6.1 填完之后的三条规则补充

**① 固守不叠加，取最高值**

A1、A3、A9、A10、B1、B2、B5 都是「固守」家族。同一回合打出多张时，对方下回合的附加 step **只算最高的一档**（与 §7.2「同向只算一次」同源）。

⇒ 否则三张固守叠起来就是 +4 step/攻击卡，对方直接不能攻击。

**② 同属性卡的差异在「触发条件 × 幅度」，不在「换一个效果」**

圆罐 7 张全是固守，是因为**属性决定效果口径**（§2.2）。构筑时选形状 = 选效果池，这就是构筑的意义。同一属性内做变体，靠的是阈值（+1 / +2）、触发条件（无条件 / 消耗装液罐 / 需求跨台）与附加小句（不能转移）。

**③ 预组只覆盖 5 个形状，扁 / 鼓 / 尖 缺席**

| 形状 | 在预组里 | 原因 |
|---|---|---|
| 圆 / 方 | ✅ 玄武 Base | 能装液 |
| 三角 | ✅ 玄武 Additional | 不能装液，只服务空罐需求 |
| 高 | ✅ 朱雀 Base | 能装液 |
| 长 | ✅ 朱雀 Additional | 不能装液；本版新增 A8 给它用途 |
| **扁 / 鼓 / 尖** | ❌ **不在任何工作台标记里** | 只能由**产线直接产出**，不能改形得到，也不能装液 |

⇒ 这三个形状是**预组的扩展轴**：想用「波及 / 蓄势 / 定点」，就得在 10 张罐子产线里挤位置给它们。这也顺带解释了为什么 §2.2 给它们的效果都是「不依赖装液」的写法。

#### 3.7.1 这五张各自补上的空洞

**① 破罐 / 封罐 = 「回合独占」的补偿**

Q40 裁定「回合独占、无打断」，于是玩家没法在对方回合反制。这两张卡提供了唯一的**事后反制**——对方上回合摆好的东西，你下回合拆掉。

> **独占的代价不是「没有响应」，而是「你的布置会活到我的回合」。破罐与封罐就是在收这笔账。**

**② 封罐不需要任何新规则 —— 它利用的是「重置只发生在所有者回合结束」**

| 时点 | 谁在重置 |
|---|---|
| 你回合结束 | 你重置**你的**罐子 |
| 对方回合结束 | 对方重置**对方的**罐子 |

⇒ 你打的封罐横置的是**对方的**罐子，你回合结束不碰它；对方整回合受制；对方回合结束他自己重置。**规则一行没改。**

**②b 但你指出了一件更关键的事：横置封锁的是「加工」，不是「使用」**

> 对方的罐子被横置了，但如果他手上有一张攻击卡**直接消耗这张罐子**来满足需求——**消耗不是操作**，所以他照样能打。

| 行为 | 是否算「操作」 | 横置能否阻止 |
|---|---|---|
| 入罐 / 出罐 / 改形 | **算**（消耗操作次数，产生横置） | **能阻止** |
| 产线产出 / 补充卡补入 / 转移 | 不算（物流） | 不能阻止 |
| **打出攻击卡，消耗需求中的罐子** | **不算**（结算，不是加工） | **不能阻止** |

⇒ **横置标记的是「这张卡本回合已经被加工过」，不是「这张卡不能用」。**

⇒ **封罐的真实定位：不是「冻结对方的弹药」，而是「阻止对方再攒新弹药」。它是一张节奏 / 防发育卡，不是控制卡。**

> 这条也统一了全作的三层语义：**操作（耗次数、横置）→ 物流（不耗次数、不横置）→ 消耗（不耗次数、不横置、横置也拦不住）**。

**③ 破罐 = 永久，封罐 = 暂时 —— 分工清晰**

| | 性质 | 对付什么 |
|---|---|---|
| **破罐** | 永久（罐子回公用堆，需重新生产） | 对方**已完成 / 已布置**的东西 |
| **封罐** | 暂时（对方回合结束自然解冻） | 对方**这回合想用**的东西 |

> **为什么破罐必须是「打碎」而不是「横置」**：横置会在回合结束时自然恢复，只有打碎才能越过对方的重置。这是横置规则直接推出的结论，不是随手选的。

**④ 破罐的最佳目标永远是「装液罐」**

| 目标 | 直接损失 |
|---|---|
| 空罐 | 1 个资源单元（罐子卡，可再生产） |
| **装液罐** | **2 个资源单元**（罐子 + 棋子，且液体要靠产线慢慢补） |

⇒ **「权重 = 造价」（Q36）的逻辑第三次生效**：造价高的东西，也最值得被破坏。

**⑤ 破罐是 B 类攻击卡的天然克星**

B 类必须「主台预处理 → 转移 → 从台交付」，链条最长的地方最贵。对方在从台摆好交付罐、还没交付时，一张破罐打碎交付罐 ⇒ 对方白费一个交付罐 + 一步转移。

⇒ **这正好是 B 类值 5~6 伤害的风险对价。** 收益越大，暴露面越大。

**⑥ 护堰是纯粹读心 —— 本作唯一的「预判卡」**

回合独占 ⇒ 防守只能在自己回合**预先**打出。对方这回合不打变化卡 ⇒ 你的 1 step 白费。

⇒ 花 1 step 赌对方会不会打变化卡。这是全作唯一的纯博弈。

#### 3.7.2 三个必须报告的问题

**问题 A：摸牌卡在当前节奏下没有成本。**

牌库 50 − 起手 10 = 40 张，每回合抽 4 ⇒ **10 回合见底**。而 §4 算出的节奏是「单台 3 回合打空」，双台约 6~8 回合结束 ⇒ **Q21 的「牌库抽空即判负」几乎不会触发**。

⇒ 摸牌卡 = **纯免费的 +1 牌差**。

**三个改法（我倾向 1）**：
1. 摸牌卡改成「抽 2 张，然后弃 1 张」（净 +1，但仍需做选择）
2. 牌库缩到 **40 张 / 人**（每回合抽 4 ⇒ 7.5 回合见底，惩罚开始生效）
3. 接受它免费——把牌库见底当成「只有长局才会发生的罕见惩罚」

**问题 B：汲液与「补给 · 四蜜 / 双蜜」功能重叠。**

两者都是「从公共棋堆取液体放工作台」，差别只有数量与位置。**冗余本身不是错**，但汲液作为「变化卡」应该有辨识度。

**两个走向**：
- 保留重叠，让汲液当「额外的液体保险」
- 改成有辨识度的版本：「取 2 枚液体，**可直接装入罐子**且该罐不横置」（0 step 顶替一次入罐操作）

**问题 C（按你的纠正重新定位）：封罐的强度取决于「对方这回合还要加工多少张」，不是「对方有多少张」。**

因为你指出：**横置 不阻止 攻击卡消耗罐子**。

| 对方的处境 | 封罐的实际效果 |
|---|---|
| 手上已有成型攻击卡，只等消耗 | **几乎无效**（横置拦不住消耗） |
| 正在攒装液罐 / 正在改形 | **很强**（正好卡住加工） |
| 那 2 张恰好是唯一还能加工的 | **极强**（等于废掉对方一步半） |

⇒ **封罐是「防发育卡」，不是控制卡。** 它惩罚「还没准备好的对手」，对「已经准备好的对手」几乎无用。

⇒ **不需要改数值。** 只需要在卡面写清「被横置的罐子仍可被攻击卡消耗以满足需求」——否则玩家会误以为它是封杀。

⇒ 顺带一个正面效果：这条让封罐与破罐的分工更干净——**破罐打「已经准备好的」，封罐打「还没准备好的」**。一张管存量，一张管增量。

## 5. 工作台生成池（随机化）

你的裁决：**玄武 / 朱雀这两张是「已默认」的固定台（Ban 已定）；未来出的工作台一律随机生成，池子可以很大，玩家自己决定往构筑里放哪 5 张。**

### 5.1 这不是新造的，是原系统现成的结构

| 原系统事实 | 卡牌里的用途 |
|---|---|
| `Config/Rules.cs:11-15` `WORKSHOP_TEMPLATES` 就是 **BaseMarks / AdditionalMarks / Ban 三个正交字段** | 换一组字段 = 换一个台 |
| `Config/Vocabulary.cs:8-10`：「形状只是名字，它能怎么变由工作台的 `WorkshopCapability`（标记）决定」——换标记不必改规则引擎 | 随机生成**不需要写新规则**，只是换数据 |
| `Domain/Workshop.cs:91-100` `ReplaceCapability`：「只换规则参数不动罐子与液体」「允许存在形状不在新标记里的罐子」 | 换台时台上资源不必清空 |

> **标记本来就是「可配置的参数」，卡牌化以后这个「可配置」直接变成「构筑资源」。** 这是本次转译里最省力、收益最大的一处复用。

### 5.2 生成规则（提案）

| 字段 | 取值 | 对玩法的作用 |
|---|---|---|
| **BaseMarks** | 从 8 形状取 **1 或 2** 个 | 决定**属性**（被克面）+ **哪些形状能装液** |
| **AdditionalMarks** | 取 **1** 个不在 BaseMarks 里的形状 | 只决定**能改形成什么**；**不能装液** |
| **Ban** | 酒 / 蜜 / 无 | 决定**液池格颜色**；无 Ban ⇒ 黑白格都有 |
| 血量 | 20（暂统一） | 后续差异化 |
| 罐位 | 6 | |
| 液池 | **双 base 5 格 / 单 base 4 格** | 按可存液体着色 |

**组合数**：BaseMarks 单/双 = 8 + 28 = 36 种；Ban 3 种 ⇒ **约 108 种工作台原型**。

### 5.3 随机化暴露出的结构性问题（必须现在决定怎么配平）

**BaseMarks 越多，被克面越大。**

「同向只算一次」（Q19=a）意味着：目标台只要有**任意一个** base 形状被你的攻击属性克，就吃 ×3/2。

| 目标台 | 圆攻击打它 | 方攻击打它 | 高攻击打它 |
|---|---|---|---|
| **纯圆台** | 1.0 | 2/3 | 2/3 |
| **圆+方台** | **3/2** | 2/3 | 2/3 |

⇒ **双 base 台比单 base 台更容易被放大伤害。**

**但双 base 的收益被我上一版严重低估了。** 装液罐的形状只能在 **BaseMarks** 里选（§6.3 入罐规则、`规则.txt:11-13`）——所以：

> **BaseMarks = 你的「装液攻击属性池」。**

单 base 台只有一条装液属性线（只能造一种属性的装液罐），双 base 台有两条。

⇒ 真正的交换是：**更宽的攻击属性池 ↔ 更大的被克面。** 这才是配方该动的地方——不是「多一种形状」这么轻飘飘的收益。

**三个配平方向（我倾向 A）**：

- **A. 双 base 台血量更高 / 液池格更多** —— 正好接上你 Q41 留的口子「以后把血量做成卡面形状属性」，让配平参数少一个，不是多一个
- B. 双 base 台允许 **Ban 两种液体**（用更宽的槽换更脆的身）
- C. 接受不对称，构筑时玩家自己权衡

### 5.4 对预组的影响

v0.3 §3.1 的镜像是 玄武×3 + 朱雀×2。随机池一开，玩家可以自己拼属性组合——例如「全单 base 台」的坦克流，或「圆+方 / 高+长」的双 base 爆发流。

⇒ **牌面模板不用改，只是「能选的工作台」变多了。**

| **棋子** | 黑 / 白各 **20 枚** | 液池 5 + 罐位 6 = 单方上限 11，双方 22，20 枚略紧但够（短缺时按 §2.3 用替代物） |
| **§5.3 配平三选一** | **选 A 的弱化版：只调液池，不动血量** | 液池格和 BaseMarks 讲的是同一件事——**装液能力**。用液池补偿双 base，配平参数少一个而不是多一个（对接 Q41「以后把血量做成卡面形状属性」的口子，但不现在动血量） |
| **酒属性解禁的工作台** | **不进预组**，留给 §5 随机池 | 预组要镜像、要简单；第二液体进预组只会让 6 张液体产线更臃肿 |
| **变化卡三问** | A 不管 / B 已裁决（汲液颜色任选）/ C 已用三层语义重定位 | §3.7 |

### 7.4 五条发现

#### 1. 圆属性在预组里通吃（最严重）

按 §11 环序（圆→方→三角→高→长→扁→鼓→尖，克 +1 与 +3）实算：

| 攻击属性 | vs **玄武**（圆+方） | vs **朱雀**（高） |
|---|---|---|
| **圆** | **3/2** | **3/2** |
| 方 | 2/3 | 1.0 |
| 三角 | 2/3 | 1.0 |
| 高 | 2/3 | 1.0 |
| 长 | 2/3 | 2/3 |
| 扁 | 1.0 | 1.0 |
| 鼓 | 3/2 | 2/3 |
| 尖 | 3/2 | 1.0 |

**圆是唯一对两个台都 ×3/2 的属性，而且没有任何一台能抵抗它**——圆被扁与尖克，而这两个形状都不在预组任何工作台的 BaseMarks 里。

⇒ 双方正解都是「拼命打圆卡」：圆卡既**最多**（7/16）又**最强**。**这不是构筑选择，这是唯一解**——而构筑选择恰恰是这套系统承诺要给玩家的东西。

#### 2. 装液攻击卡把主台锁死了

**A7 蜜炮**（1 空高 + 1 装蜜高，A 类只能主台打）。但**装蜜高罐只能在 BaseMarks 含「高」的台上入罐**。
⇒ 主台若是玄武，**A7 根本做不出来**。

这不是 bug，是 §5.3「BaseMarks = 装液属性池」的直接后果。但它意味着 16 张攻击卡里有一批是**「特定主台专属」**的：构筑时必须先定主台，再看哪些装液卡可用。

#### 3. 液体产能远超消耗

蜜快线 0.4/tick = 4 枚/回合，实际消耗 1~2 枚/回合。液池 5 格每回合溢出 2 枚。
⇒ §6.2 的担忧被证实：**液体产线 6 张太多**，场上实际只需要 1 张。

#### 4. step 根本不稀缺（设计意图落空）

| 吃 step | 不吃 step |
|---|---|
| 入罐 / 出罐 / 改形 / 转移 / 换台 | **攻击卡 / 产线卡 / 补充资源卡 / 工作台卡** |

一回合 4 步，实际只用 **1~2 步**，剩 2~3 步空转。

**连带后果：整个「固守」族失效。** 固守是给对方的攻击卡加 step 税，可对方本来就用不完 step ⇒ **加税等于没加**。圆属性 7 张卡的主效果，在当前 step 供给下是空的。

#### 5. 产线区 3 格把后续路线锁死了

T1 铺了 圆圆蜜，3 格满了。而 **A9 三叠**要 1 空方罐 + 1 空三角罐——没有方/三角产线，也换不上去。

⇒ **规则里根本没有「产线区换线」的流程。** 这是缺失，不是设计。

### 7.5 建议（按影响排序）

| # | 问题 | 建议 | 影响面 |
|---|---|---|---|
| 1 | 圆通吃 | **改 §11 环序**，让圆不再同时克方与高。一个可用候选：**圆 → 方 → 三角 → 长 → 高 → 扁 → 鼓 → 尖**，算下来 圆 1.5/1.0、方 0.67/1.5、长 0.67/1.5，没有属性通吃，且不改任何卡面字段。（备选：把朱雀 BaseMarks 从「高」改成「尖」——尖克圆，一刀切断，但偏离原系统模板） | 全卡表伤害值 |
| 2 | step 不稀缺 | **N 从 4 降到 3**，或给攻击卡加 1 step 成本 | N、固守族、变化卡 |
| 3 | 液体产线过剩 | **液体产线 6 → 4**，腾 2 张给 A 类攻击 | 预组配比 |
| 4 | 产线区锁死 | 补规则：**回合内可用 1 张新手牌产线替换场上 1 张，耗 1 step** | 新增流程 |
| 5 | 主台专属卡 | 在 §3.5 / §3.6 对每张装液卡标注「要求主台含 X」 | 卡表注释 |

> 我这轮**只报告不动手**：上面 5 条里有 3 条要改你已经裁决过的东西（环序、N、预组配比），改之前需要你点头。
