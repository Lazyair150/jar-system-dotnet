# 第 2 步设计：战斗内核

> 状态：**待你拍板**。第 1 步（解谜版 A + 剪四）已完成并通过四关可解性验证。
> 本文档只定第 2 步的骨架，第 3 步只给预告。

---

## 一、第 2 步要做什么

把现在的「单关解谜」变成「一场战斗」：

```
战前配置  →  敌人出一族订单  →  引擎自动结算  →  完成几个订单 = 打它几下
     ↑                                                    ↓
     └────────────  敌人加一条新约束，你重配  ←────────────┘
```

**它仍然完全是第 1 步那个引擎**：配置、产线、罐位、液池、禁令、自动结算、下界进度，一个都不改。
新增的只有三层外壳：**敌人的约束**、**订单的面值**、**胜负的判定**。

## 二、三条不能破的线（来自前面几轮的分析）

| 线 | 为什么 | 落到第 2 步 |
|---|---|---|
| **不能出现时间压力** | 「确定性引擎 + 赶时间 = 作业」，这是 demo 不好玩的根因之一 | 没有回合数硬上限，没有倒计时 |
| **伤害不能是罐子数量的线性函数** | 全信息 + 线性 + 无反应窗口 ⇒ 退化成「谁投的罐子多」 | 伤害由**订单面值**决定，不由你投了几个罐子决定 |
| **成长只能换约束，不能换数值** | 「越来越多绿色高亮」的终点是「全绿」，那时游戏就结束了 | 掉落的是新工作台 / 新产线 / 新订单族，不是「攻击 +2」 |

## 三、核心循环（我的提案）

### 敌人不「打你」，它**改世界**

敌人每回合结束做一件事：**加一条约束**。约束有三种，全部**提前一回合预告**：

| 约束 | 效果 | 依据 |
|---|---|---|
| **禁一种液体** | 你所有台的该液体容量变 0，且不能当改形成本 | 原系统 `IsBanned` 语义，直接复用 |
| **封一种形状** | 该形状不能作为产线产出，且不能改形得到 | 相当于临时删掉一个 BaseMark / AdditionalMark |
| **缩一格罐位** | 罐位上限 6 → 5 | 原系统 `MaxJars` |

**关键**：约束是**可读的、可预告的、可对抗的**。它不夺走你的时间，它夺走你的**可解空间**。

### 你也不「打它」，你**把它的题解掉**

敌人每回合出 **2–4 张订单**（一个「订单族」），每张订单有：

- `面值`：完成它造成的伤害（1–4）
- `需求`：就是现在这套 `reqs`
- `时限`：**不做时限**，订单会一直留在场上，直到你做完或者被新订单挤掉

每回合自动结算后：

- 完成的订单 → 造成面值伤害 → **并且夺回一条正在生效的约束**（你吃了它的题，它的约束就松一格）
- 没完成的 → 留在场上，下回合接着长（第 1 步的 prep 机制已经在做这件事）

### 胜负

| | 条件 |
|---|---|
| **赢** | 敌人血量归零 |
| **输** | **约束累积到把你锁死**——不是我定一个数字，而是引擎判定「当前配置下，场上没有任何一张订单能达到 1/2 以上进度」。**这是真的锁死，不是感觉锁死。** |

> 这条是整个第 2 步最重要的设计。输的条件不是「回合到了」，而是「**你的世界被压缩到再也长不出东西**」。
> 它恰好是引擎能精确回答的问题——第 1 步那个下界判定 `grow()` 返回 0 就是锁死。**用游戏机制本身当失败条件，而不是外挂一个计时器。**

## 四、订单面值怎么定

面值 = **这张订单在这个世界里的稀有度**，不是它的需求数量。具体给法：

```
面值 = 3  —— 需求里包含「附加标记形状」（三角/长/扁/鼓/尖 中当前台不产的那些）
面值 = 2  —— 需求里包含装液罐
面值 = 1  —— 纯基础形状纯空罐
```

这样「难做的订单更值钱」，而「难做」是从**当前约束**里长出来的，不是写死的数字。

## 五、需要你拍板的三个点

### 决策 A：敌人加约束 vs 敌人扣产能

- **加约束（我推荐）**：封形状/禁液体/缩罐位。可预告、可对抗、逼你换配置——**换配置正是这个引擎唯一的核心动词**。
- **扣产能**：产线速率 2 → 1。更直觉，但它只是让你变慢，不逼你改变做法，最后退化成等。

### 决策 B：约束被「夺回」还是「永久累积」

- **可夺回（我推荐）**：完成订单就松一格。于是「解它的题」既是伤害又是解围，一件事两个作用，规则不用多加。
- **永久累积**：更像真压力，但会变成单向下坡——一旦落后就再也追不上，且玩家会觉得自己被耍。

### 决策 C：一场战斗多少回合量级

- **10–14 回合**（我推荐）：够玩家至少换两次台、撞一次锁死边缘。
- **20+ 回合**：更像「经营」，但引擎的张力撑不住那么长，后半段会腻。
