# 陶罐对战 · 规则草案 v0.1

> 来源：`D:\codex\jar-system-dotnet` 陶罐系统的**机制转译**。
> 铁律：机制内核不变，只改承载形态；因果链不能断。

---

## 0. 一句话

你是匠人。你的**工作台**是你在战场上的代理人。**罐子**与**液体**是你的弹药，**攻击卡**是订单——订单要什么资源，你就得凑什么资源。

**属性由弹药的成本决定：想打某种属性，你得先有一条能造出它的产线。**

---

## 1. 核心循环

```
产线产罐子 → 改形/装液 → 凑出攻击卡的需求 → 打出攻击卡 → 打对方工作台
                   ↑                                    │
                   └──── 对方回合里动你的罐子 ←── 你转移暴露了意图
```

## 2. 组件

### 2.1 卡牌（每人牌库 50 张）

| 类别 | 说明 |
|---|---|
| **工作台卡** | BaseMarks / AdditionalMarks / Ban / 血量 20 |
| **资源生产卡** | 产出类型（罐子/液体）+ 形状或液体种类 + 速率 |
| **补充资源卡** | 直接给资源，**留手牌为暗牌** |
| **攻击卡** | 需求（罐子列表）+ 基础伤害 + 效果 + 卡类（A/B） |
| **变化卡** | **step 成本** + 效果 |

- 起手 10 张；每回合开始抽 4 张；手牌上限 10。

### 2.2 罐子卡（**公共供应堆**）

- **8 种形状 × 4 张 = 32 张**，单面
- 卡面只印形状，**中央留白放棋子**
- 产线产出罐子时从供应堆取一张；罐子被消耗/摧毁时进弃置堆

### 2.3 棋子（液体）

| 棋子 | 液体 |
|---|---|
| **黑棋** | 酒 |
| **白棋** | 蜜 |

- 各 **20 枚**；缺失时用象棋红/黑替代
- **液体恰好两种**是原系统宪法（`设计分析_世界内核与成长框架.md:159`），恰好等于"只需要两种颜色的棋子"

### 2.4 其它

血量标记（0–20，每方 2 组）、step 标记（0–4）、弃置堆

## 4. 五类卡

### 4.1 工作台卡

- 字段：名称 / **BaseMarks** / **AdditionalMarks** / **Ban** / 血量 **20**
- **BaseMarks** 决定：能改形成什么 + **相克属性**
- **AdditionalMarks** 只决定：能改形成什么（**不参与相克**）
- **Ban 封锁该液体的全部获取途径**：不能倒入、不能存储、不能做成本

**模板（原系统）**

| 工作台 | BaseMarks | AdditionalMarks | Ban |
|---|---|---|---|
| 玄武台 | 圆罐、方罐 | 三角罐 | 酒 |
| 朱雀台 | 高罐 | 长罐 | 酒 |

### 4.2 资源生产卡

- 字段：产出类型（罐子 / 液体）/ 形状（产罐子时）/ 液体种类（产液体时）/ **速率（分数）**
- **只能放进产线区**
- **产出的罐子直接进主台**（原系统 `FlowToMaster` 语义）
- 速率是分数（如 `0.2/tick`）；**回合结束结算 10 tick**，余数跨回合累计

### 4.3 补充资源卡

- 字段：给的资源（罐子形状 / 液体种类 + 数量）
- **留在手牌为暗牌**，玩家自己决定何时给出、给主台还是从台

### 4.4 攻击卡

- 字段：**需求**（罐子列表）/ 基础伤害 / 效果文字 / **卡类 A 或 B**
- **打出不耗 step**
- 打出时，需求中的罐子**连同其上棋子一并进弃置堆**
- **A 类：需求必须在主台独自满足**
- **B 类：只能在从台打出，需求可主从联合**（跨台需付转移步数）

### 4.5 变化卡

- 字段：**step 成本**（卡面印刷，基础档 1）/ 效果
- **不耗资源**

## 5. 回合流程

```
【回合开始】
  1. 从牌库抽 4 张（牌库空 ⇒ 判负）
  2. step 重置为 4

【行动阶段】可任意顺序，累计消耗 step
  · 放置工作台卡                     0 步
  · 放置资源生产卡                   0 步
  · 打出攻击卡（消耗资源）             0 步
  · 打出补充资源卡                   0 步
  · 打出变化卡                       按卡面
  · 罐子操作（入罐/出罐/改形/转移）      每次 1 步
  · 换台                             1 步

【回合结束】
  1. 各产线区结算 10 tick 产出
  2. 手牌弃至 10 张
  3. 交接
```

## 6. 资源与操作

### 6.1 罐子

- 每台罐位上限 **6**；超出**直接丢弃**，不回收
- **一罐一操作**：同一回合内，每张罐子卡最多被操作**一次**

### 6.2 液体

- 每台液池上限 **6**
- 液体有两个位置：**液池**（游离）/ **罐子卡上**（装入）
- 一个罐子最多装 **1 枚**棋子

### 6.3 操作表（各 1 步）

| 操作 | 条件 | 效果 |
|---|---|---|
| **入罐** | 空罐 + 形状属该台标记 + 液体不被该台 Ban + 液池 ≥1 | 液池 −1 → 罐子卡 +1 |
| **出罐** | 罐子卡上有棋子 | 罐子卡 −1 → 液池 +1 |
| **改形（空罐）** | 空罐 + 液池有非禁成本液体 | 液池 −1（**消耗**）；形状改变 |
| **改形（满罐）** | 罐子卡上有棋子 | 移除该棋子（**弃置**）；形状改变 |
| **转移** | 罐子在 A 台，目标 B 台 | 罐子卡（连棋子）移到 B 台 |

### 6.4 改形规则

- **基础标记** → 其它基础标记 + 全部附加标记
- **附加标记** → 只有基础标记（**死胡同**）
- **不在任何标记中** → 全部基础标记

## 7. 伤害结算

### 7.1 属性判定（可从需求直接推出，无需记忆）

对需求中每种形状计算**加权和**：

| 罐子状态 | 权重 |
|---|---|
| 空罐 | **1** |
| 装液罐 | **2** |

- **属性 = 加权和最大的形状**
- **平局 = 取需求列表里先出现的**

**例**：`1 空方罐 + 1 装酒圆罐` → 方 1 : 圆 2 ⇒ **圆罐属性**

> 权重就是造价：装液罐 = 罐 1 + 液 1 = 2 个资源单元。

### 7.2 相克乘算

- 攻击卡属性 vs 目标工作台的 **BaseMarks**
- **克制 ×3/2**，**抵抗 ×2/3**
- **同向只算一次**（多个克制不叠加、多个抵抗不叠加）
- ⇒ 伤害恒在 **[2/3, 3/2]** 倍，最大 2.25 倍差
- 伤害向下取整，最低 1

### 7.3 目标

**攻击者自行选择打主台还是从台。**

### 7.4 死亡

- 工作台血量 ≤ 0 ⇒ **该台连同台上所有罐子卡与液池棋子进弃置堆**
- **从台死**：位置空着，允许
- **主台死**：
  - 本回合结束前，可主动用手牌工作台卡补入主位
  - 否则回合结束时**从台强制替补为主台**（带剩余血量）
- **场上无任何工作台** ⇒ 进入对方回合，该回合结束仍未补台 ⇒ **判负**

---

## 8. 胜负

1. 对方场上无工作台且其回合结束未补台 ⇒ **胜**
2. 对方牌库抽空 ⇒ **胜**
3. 无"玩家血量"——血量挂在工作台上

## 9. 换台流程

想把手牌的工作台卡放到某个位置时：

| 位置状态 | 处理 |
|---|---|
| **空** | 直接放入 |
| **有台，但台上无资源**（无罐子、液池空） | **直接换**，旧台进弃置堆 |
| **有台且台上有资源** | 进入**换台流程**（见下） |

**换台流程**（消耗 1 步，内部操作不额外耗步）：

- **Ban 相同** ⇒ *Case 1*：把游离液体尽量灌进旧台的 BaseMarks 空罐（新台接收"已装满的罐子"作为额外液体容量）
- **Ban 不同** ⇒ *Case 2*：旧台**临时获得新台 BaseMarks 作为附加标记**，把旧台罐子改形成新台形状；游离液体不强行清空
- 之后按禁令/容量**转移**，未用的资源**回流**；回流溢出直接丢弃
- **主台不能设为从台**

## 10. 首轮与特殊时钟

- **首轮**：双方的第一回合都**不能对对手使用卡牌**（只能建设）
- **产线结算**：回合结束结算 10 tick；**本回合放下的产线本回合结束就结算**（资源在下一回合可用）
- **宽限回合**（场上无工作台时）：可放工作台卡、可放产线卡、可用变化卡；**不能操作资源**
- **无打断**：回合独占，对手不能在你的回合出牌；但**转移是公开信息**，对手看得见你蓄力
- **失败即代价**：已经花掉的成本不退（已改形的形状、已消耗的液体、已倒入的液体都留在场上）

## 11. 八属性克制环（提案）

**环序**：圆 → 方 → 三角 → 高 → 长 → 扁 → 鼓 → 尖 →（回圆）

**每个属性克：其后第 1 位、第 3 位**

| 属性 | 克制 | 被克 |
|---|---|---|
| **圆罐** | 方罐、高罐 | 尖罐、扁罐 |
| **方罐** | 三角罐、长罐 | 圆罐、鼓罐 |
| **三角罐** | 高罐、扁罐 | 方罐、尖罐 |
| **高罐** | 长罐、鼓罐 | 圆罐、三角罐 |
| **长罐** | 扁罐、尖罐 | 方罐、高罐 |
| **扁罐** | 鼓罐、圆罐 | 三角罐、长罐 |
| **鼓罐** | 尖罐、方罐 | 高罐、扁罐 |
| **尖罐** | 圆罐、三角罐 | 长罐、鼓罐 |

- 每个属性**克 2、被克 2**，完全对称
- **语义可换**：形状的"性格"（方罐多攻击、圆罐多防御、三角罐多机制、长罐多回复）只是**风味文字**，不进数值
- **玄武（圆+方）vs 朱雀（高）**：互相 ×3/2 ⇒ 互相打得都更重（多属性工作台趋于中和，单属性工作台偏科）
