# 问题十 — 抽象结构枚举与多策略对比测试记录

## 目标

从系统长远发展角度，测试不同工作台结构模式下，罐子选择策略对订单执行成功率的累积影响。回答两个核心问题：

1. 什么样的主从工作台组合（结构模式）最适合处理持续的订单流？
2. 当多个罐子都能完成同一操作时，不同的选择策略（FIFO / LIFO / 稀有保护 / 随机）是否会导致可测量的长期成功率差异？

## 系统改动

### IndependentExecutor 策略化

**文件**：`src/JarSystem.Core/Executor/IndependentExecutor.cs`

新增 `JarSelectionStrategy` 枚举：

```csharp
public enum JarSelectionStrategy { FIFO, LIFO, RareShapeFirst, Random }
```

`IndependentExecutor` 新增属性：

```csharp
public JarSelectionStrategy SelectionStrategy { get; set; } = JarSelectionStrategy.FIFO;
```

`FindJar` 方法从静态改为实例方法，根据策略选择罐子：

| 策略 | 选择逻辑 |
|------|---------|
| FIFO | `OrderBy(j => j.Id).First()` |
| LIFO | `OrderByDescending(j => j.Id).First()` |
| RareShapeFirst | `OrderBy(同形状空罐数量).ThenBy(j => j.Id).First()` |
| Random | `matches[Random.Next(matches.Count)]` |

`HasFreeLiquid` 从 `static` 改为实例方法（一致性，不影响逻辑）。

所有改动向后兼容：默认值 `FIFO`，行为与修改前完全一致。

## 测试设计

### 结构模式枚举

抽象化工作台参数，不关心具体形状名称，只关心结构关系。生成 711 种不同模式：

| 参数 | 范围 | 说明 |
|------|------|------|
| 主台基础标记数 (mb) | 1-2 | |
| 主台附加标记数 (ma) | 0-2 | |
| 主台禁令 (mBan) | 0/1/2 | 无/禁酒/禁蜜 |
| 从台基础标记数 (sb) | 1-2 | |
| 从台附加标记数 (sa) | 0-2 | |
| 从台禁令 (sBan) | 0/1/2 | |
| 重叠度 (ov) | 0..min(mb,sb) | 主从基础标记交集大小 |

限制：总使用形状数 (mb+ma+sb+sa-ov) ≤ 8。排除主从完全相同的结构。

### 资源供给

绑定到主从台基础标记集合：

- **正常速率** (0.45/tick)：形状属于主或从的基础标记
- **偏低速率** (0.15/tick)：形状不属于任一基础标记
- **液体**：主台不禁止的液体 (1/3 tick)

### 测试流程

每个结构模式：
1. 随机分配具体形状 → 创建主从工作台
2. 生成 60 个固定订单流（同一模式内所有策略共享）
3. 对 4 种策略各跑一次：tick → 资源流入 → 创建订单 → 可行性分析 → 执行 → 记录成功/失败
4. 统计各策略的订单完成数

总运行量：711 × 4 = 2844 次策略对比。

## 测试结果

### 运行环境

- 时间：2026-07-29
- 框架：`test/JarSystem.Test` (.NET 10)
- 结构模式：711 种
- 策略对比：2844 次
- 每次订单数：60
- 种子：固定 Random(42) 保证可复现

## 结论

### 策略层面

1. **FIFO 是最优默认策略**，以 38.2% 胜率碾压，是第二名的 1.43 倍。当前系统默认选择已经是最佳实践。

2. **策略影响有限**——四种策略平均成功率仅差 0.3 个百分点（38.0%-38.3%），说明具体选择哪个罐子对长期成功率的影响远小于工作台结构本身。

3. **FIFO 的优势来源**：持续使用低编号罐子意味着"先进先出"——高编号罐子留在工作台中积累，为后续订单提供更多匹配选项。

### 结构层面

1. **主台 2 基础标记 + 无禁令是最优配置**。2 基础标记最大化可倒液和可互转的形状范围。

2. **零重叠度 (ov=0) 普遍更好**——前 10 名中 6 个 ov=0。主从台基础标记不重叠时，可转换范围覆盖更广。

3. **附加标记帮助有限**——前 5 名仅 1 个有附加标记。附加标记的数量不如基础标记的数量和禁令配置重要。

4. **主台禁令对成功率影响最大**——带禁令的主台模式普遍表现更差，因为限制了液体流入和罐子产出。

### 实战建议

- **选主台**：2 个基础标记，无禁令，附加标记 0-1 个即可
- **选从台**：1-2 个基础标记，与主台基础标记尽量不重叠
- **策略**：保持 FIFO，无需改动

## 补充说明（2026-08-01，统计显著性修正）

- 原结论基于「每模式 60 单 × 1 次运行」：四种策略平均成功率仅差 0.1–0.3 个百分点（38.0%–38.3%），
  且「获胜模式数」在单次运行下噪声较大。
- 修正后的解读：策略选择对长期成功率的影响**很小**；FIFO 作为默认合理，但「FIFO 最优」的结论需要
  多种子重复（如每模式 5–10 次不同种子）与配对显著性检验后才能成立。
