## 关键技术变更

### 1. WebSocket → SignalR

原版使用原生 WebSocket 进行实时通信，.NET 版改用 **SignalR Hub**：

```
连接: /hub
协议: JSON
服务端推送: connection.on("state"), .on("init"), .on("orderExecuted")...
客户端调用: connection.invoke("HandleCommand", type, data)
```

### 2. Express → ASP.NET Core

```
原版: Express + http.createServer + ws
移植: WebApplication + SignalR + StaticFiles
```

### 3. CommonJS → C# 命名空间

所有模块从 `require/module.exports` 转为 `namespace/class` 结构，命名空间按多级目录组织。

### 4. Action 模式

原版存在两套操作机制（旧 Action 模式 + Command 模式），移植仅保留了 Command 模式（PourInCommand、ReshapeEmptyCommand、ReshapeAndPourCommand、PourOutCommand、TransferCommand），这是原版 BUG 修复后的正确路径。

### 5. 前端适配

前端从 EJS 模板（服务端渲染）转为纯静态 HTML + SignalR 客户端库（CDN），通过 SignalR 实时获取状态。

- SignalR 客户端库: `https://cdnjs.cloudflare.com/ajax/libs/microsoft-signalr/8.0.0/signalr.min.js`
- 修改: `var ws = new WebSocket(...)` → `new signalR.HubConnectionBuilder()...`
- 修改: `ws.onmessage` → `connection.on(...)`
- 修改: `ws.send(JSON.stringify(...))` → `connection.invoke("HandleCommand", ...)`

## 注意事项

1. **中文支持**：所有中文常量（形状名、液体名、状态值）保持原样，C# 文件使用 UTF-8 编码。
2. **Windows 路径**：项目路径中包含中文，已在 `.csproj` 和代码中处理好。
3. **依赖**：仅使用 ASP.NET Core 内置 SignalR，无需额外 NuGet 包。
4. **测试框架**：原版 `_test_compare.js`（10000 个随机场景测试）尚未移植，建议后续补充。
5. **NuGet 访问**：首次 build 需要 NuGet 还原权限，已在构建过程中解决。
