起步（2026-11 现状）

一、跑起来看

  双击 run.bat（或在本目录 cmd 里）：

    run.bat

  它做三件事：杀掉旧进程 → dotnet run --launch-profile http → 6 秒后打开浏览器。
  默认地址 http://localhost:5289/world.html（世界视图）。

  想换端口或指定关卡，手打：

    taskkill /f /im dotnet.exe
    dotnet run --project src\JarSystem.Web --urls http://127.0.0.1:5299 -- --level 3

  --level N 选第 N 关（1..6，按 config\levels\ 文件名顺序）；不给就是出厂沙盒
  config\world.json（不判胜、回合不限）。


二、world.html 上有什么

  - 世界状态：每台工作台的 基础/附加/禁 标记、罐位与液池、池里有什么；
    每张订单的独立进度条（以当前资源这单能走到哪一步）、开始/删除/上下移；
    产线卡（每个形状 4 档速率）；新建工作台=复制现有卡片。
  - 帧时间线：内核每做一件事广播一帧（seq / tick / revision / kind / op / 主体）。
    页面只显示帧，不推导任何东西。
  - 不变量面板：内核自查有没有自相矛盾（挂空台、两单抢一个过程、罐子 id 跨台…）。
  - 命令面板：「推进一回合」按一次，世界才动一次。世界不会自己走。

  旧版的 demo/ 原型已退役（见 demo/_退役/README.md）：规则只住内核。


三、改内容 / 做新关

  关卡 = 一份世界 + 提示 + 回合上限 + 目标单数，全在 config\levels\*.json：
    { "name": "…", "hint": "…", "turns": 9, "goal": 1, "world": { … 与 config\world.json 同构 … } }
  改完直接重启，启动时会校验：任何一关坏了当场拒绝启动，不会玩到第 5 关才炸。


四、验证

  全门禁（唯一完整回路，约几分钟）：

    set CI=1
    重构报告\verify.bat

  两个必需结论：VERDICT=OK 与 QUALITY-OK。重点看 REPLAY-OK 那行的四个数字
  （commands / stateBytes / logBytes / journalBytes）——纯重构时它们不该变。

  只跑测试：

    dotnet run --project test\JarSystem.Tests\JarSystem.Tests.csproj -c Release

  网页冒烟（真点按钮，需要本机有 Chrome/Edge）：

    dotnet run --project src\JarSystem.Web --urls http://127.0.0.1:5299 -- --level 1
    node tools\web_smoke.js http://127.0.0.1:5299

  注意：门禁跑之前先 taskkill /f /im dotnet.exe，否则宿主进程会锁住 bin 下的 dll，
  门禁会报一串 MSB3061/MSB3026 和 QUALITY-FAIL（不是代码问题）。
