# 工作台资源流入：位置职责、优先级与容量策略

> 日期：2026-11-03
> 结论：主台与从台不是两个等价仓库。主台接收仓库流入；从台只在 B 类订单期间临时持有主台调来的资源，
> 订单结束前必须全部回落。

## 1. 位置职责

```text
仓库 ──唯一入口──> 主台
                     │
                     └─ B 类订单开始时选择性上移必要工具与交付物
                                  ↓
                                从台
                                  │
                                  └─ 成功/失败/取消后全部自由落体回主台
```

- 主台与仓库管道齐平，是仓库资源的唯一接收方。
- 从台是 B 类订单临时升起的工具位，不接收仓库流入。
- 有罐子或液体的工作台不能被选为从台；B 类订单开始前会再次校验。
- B 类订单结束后，从台必须排空。无运行中的 B 类订单时，从台仍有资源是错误状态。
- 活动订单过程存续期间，主台/从台位置冻结；同步 `setMaster`、事件切换与裸索引入口都不能绕过这层互斥。

## 2. B 类订单收尾

固定顺序：

1. 在从台按需求匹配并移除交付罐；
2. 枚举从台当前所有剩余罐子，逐个转回主台；
3. 枚举从台所有非零游离液体，全部尝试转回主台；
4. 主台接不下的罐子或液体直接丢弃，并计入全局丢弃账目。

必须使用“从台当前剩余物全集”，不能只处理 `TransferredJarIds` 或“转入液体账目”。
原因是路径执行中会生成新的从台状态：

- 工具罐本身可能在完成作用后仍留在从台；
- 满罐被倒出后，空罐会成为剩余工具罐；
- 倒出的游离液体若未被后续改形成本完全消耗，会把“罐内液体”变成“从台自由液体”。

因此，B 类订单可能不残留交付物，却残留工具罐或工具产生的液体。这些资源都属于临时从台，
成功、失败、取消三条路径都必须回主台。

| 从台资源 | 成功交付后 | 失败/取消后 |
|---|---|---|
| 已交付罐 | 离开世界并记入交付审计 | 不存在 |
| 未交付工具罐 | 回主台；主台满则丢弃 | 回主台；主台满则丢弃 |
| 转入后未使用的游离液体 | 回主台；主台容量不足则丢弃 | 回主台；主台容量不足则丢弃 |
| 工具罐倒出后剩余的游离液体 | 回主台；主台容量不足则丢弃 | 回主台；主台容量不足则丢弃 |

从台不再有“原有资源保留”这一分支：从台在原系统里曾是第二仓库，新模型中没有这项职责。

## 3. 同一 tick 内的优先级

固定管线顺序：

```text
事件 → 修饰器 → 过程 / 订单收尾 → 世界产出 → 仓库流入
```

B 类收尾发生在过程阶段，因此：

1. 工具罐、剩余罐和全部从台液体先回流主台；
2. 同一 tick 的仓库流入随后只能使用主台剩余容量。

这是由阶段顺序表达的显式资源优先级。仓库流入不会抢在从台回落之前占掉主台容量。

## 4. 工作台接收接口的职责

`Workshop` 提供容量原语：

- `AddJar` / `TransferIn`：罐子接收，全有或全无；
- `AddLiquid`：液体接收，全有或全无；
- `TryReceiveLiquid`：液体部分接收，返回实际接收量；
- `HasResources`：判断工作台是否仍有罐子或非零液体。

它不判断资源来自仓库、订单转移、从台回落还是换台。调用方决定策略：

| 调用方 | 罐子策略 | 液体策略 |
|---|---|---|
| `Warehouse.FlowToMaster` | 主台满则停止，罐子留在仓库 | 容量内部分接收，余量留在仓库 |
| B 类主台→从台转移 | 目标从台满则整批失败 | 容量内部分接收，余量留在主台 |
| B 类从台→主台收尾 | 从台全集逐罐转出，主台满则丢弃 | 从台全集逐种转出，主台容量不足则丢弃 |
| 工作台切换 | 按价值排序，收不下则丢弃 | 新台禁令/容量不允许则整笔丢弃 |
| 现场缩小容量 | 超出罐位直接裁掉并计数 | 每种液体超出部分裁掉并计数 |

## 5. 主台切换边界

主台切换不是订单，也不把资源搬去“从台”。它是主台位置的水平替换：

1. 目标工作台进入待切换位置；
2. 旧主台通过切换规则重组并转移资源；
3. 异步迁徙过程存续期间，仓库→主台入口关闭；
4. 迁徙完成后目标工作台承担主台职责；
5. 下一个 tick 恢复仓库流入，库存不会跨世界阶段提前落位。

仓库库存只留在仓库；暂停的是“搬运到主台”，不是生产入库。
