## 基线

- 基于 Jar Core PR #60 当前目标分支快照：`8ea8106367a9246a4e97aee3191f10114c1f2f99`。
- 本切片只扩展 9c 资源模拟器的固定输入样本，不改变领域语义或生产求解路径。
- 固定随机种子：`0x51EED`；样本数：512。
- 测试文件：`test/JarSystem.Tests/WorldV2/WorldOrderSymbolicResourceSimulatorTests.cs`。

## 每个样本覆盖的守恒关系

- 主台：初始余额 + 本次被接收产液 - 一次性交接量 = 最终余额。
- 从台：交接收入 - 从台游离液体消耗 = 最终余额。
- 本程序产生的 1 单位游离液体，完整落入 accepted 或 discarded。
- discarded 等于 rejected 与 overflow-discarded 之和。
- 交接成功当且仅当实际转移完整的 1 单位；失败时不得部分转移。
- 两个岗位的峰值 staging 余额均不得超过各自容量。
- 同一固定输入重复模拟，状态、交接结果和转移向量必须一致。

## 边界

本测试只证明固定 B 类符号程序在所枚举容量/初始余额下的账户守恒与重放确定性。它不证明所有规则程序的完备性、不替代物理 Jar/Manifest/Admission/Lease 的端到端验证，也不将单个候选失败解释为订单全局无解。
